# 다이빙 수요로 보는 해안 관광 계절성

한국관광공사 **한국관광 데이터랩**의 지역별 관광지 검색순위 데이터로
전국 해안 시군구의 다이빙 수요 계절성을 일반 관광과 대조한 공개 대시보드입니다.

**https://nomadit.github.io/dive-season-kr/**

## 무엇을 보여주나

- **다이빙 특화지수** — 같은 지역·같은 달의 다이빙 검색 점유율 ÷ 일반 관광(자연관광) 검색 점유율.
  1.0을 넘으면 그 달은 일반 관광보다 다이빙 쪽으로 수요가 쏠린다는 뜻입니다.
- **계절 중심월** — 검색량 가중평균으로 낸 '그 해의 중심이 되는 달'.
- **지역별 정점** — 시군구별로 다이빙 특화가 가장 높은 달.

## 한계

**수치는 검색량이며 실제 방문량이 아닙니다.** 검색은 방문 의향의 선행 지표로 읽되,
방문자 수로 환산하지 않았습니다.

다이빙 검색량이 기간 누적 1,000건 미만인 지역은 표에서 제외했습니다.
기준선이 작은 달에 검색 몇 건만 잡혀도 지수가 부풀기 때문이며,
제외한 지역은 화면 하단에 그대로 표기합니다.

업체 분류에서 관광 잠수함·씨워킹·서핑은 다이빙과 구분해 제외했습니다.
